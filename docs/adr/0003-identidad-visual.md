# ADR-0003 · Identidad visual propia sin logotipos oficiales
**Estado:** aceptada · 2026-11-13
**Contexto.** El objetivo es la fidelidad de navegación y formularios, pero el escudo nacional, el logotipo del SAT y la marca gob.mx son identidad del Estado.
**Decisión.** Replicar estructura, orden de campos, textos y paleta (guinda, dorado, oscuro) con la marca "SSAT · Simulador académico"; banda roja permanente en todas las pantallas; acuses con sello "SIN VALIDEZ FISCAL". Revisión jurídica antes del piloto.
**Consecuencias.** Menor riesgo legal; el sistema de diseño define tres temas; las capturas reales se usan solo como referencia interna.
